# Security Policy
## Supported versions
Security patches for our projects are generally only released for the latest available version. Preview builds will always receive the same security patches as the mainstream builds.
## Reporting a security vulnerability
We actively welcome the reporting of security issues to help keep our projects safe. Vulnerabilities found in any of our projects can be privately reported through GitHub's "Security and quality" option in the project's repository via the "Report a vulnerability" button. Alternatively, you can join [our Discord](https://discord.gg/GeyserMC) and use the form in the [#exploit-report](https://discord.com/channels/613163671870242838/1406398409417691157) channel. Once submitted, our security team will evaluate your report and follow-up if additional context is needed. We try to keep you informed in every step whilst we deploy the patch.

We generally try to publish a security advisory within a reasonable time after releasing the patch.
### Regarding AI usage
You may use AI models to analyse security issues in our projects, however we would prefer reports to be written by yourself, with little assistance of an LLM. Please do verify any issues AI models raise yourself before reporting them to us. Our [AI policy](https://github.com/GeyserMC/.github/blob/master/AI_POLICY.md) applies here!
